# РГАТУ · Студент

Неофициальное единое приложение студента РГАТУ.

## Архитектура

Проект теперь разделён на два независимых приложения:

- `frontend/` — Vite PWA. Никакого PHP-рендеринга.
- `backend/` — Yii3 JSON API.
- MariaDB — основное серверное хранилище.
- `public/` — предыдущая статическая сборка, временно оставлена как безопасный снимок до завершения миграции фронта.

Цель — объединить расписание, ЛК1, ЛК2, профиль, сессии, ДКР, задолженности и университетские сервисы, не привязывая UI к конкретному источнику данных.

## Локальный запуск frontend

```bash
cd frontend
npm install
npm run dev
```

## Локальный запуск backend

```bash
cd backend
cp .env.example .env
composer install
php yii serve
```

API v1 начинается с `/api/v1`.

Стабильный модуль расписания пока остаётся встроенным статическим модулем и будет постепенно переведён на API.
