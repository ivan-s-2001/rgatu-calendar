# РГАТУ · Студент

Неофициальное единое приложение студента РГАТУ.

Цель — объединить расписание, ЛК1, ЛК2, профиль, сессии/ДКР, задолженности и официальные сервисы в одном интерфейсе. Продукт не привязан к ФЗО: форма обучения является свойством профиля и источника данных.

Первая версия — installable PWA. Внутрь переносится стабильный модуль расписания из `ivan-s-2001/rgatu-schedule` на commit `18df96f4d862fc10c199e93a1a274a17dae23e35`; исходный проект расписания остаётся независимым.

ЛК1 и ЛК2 пока открываются на официальных доменах. Приложение не хранит университетские пароли.

См. [архитектуру](docs/ARCHITECTURE.md).
