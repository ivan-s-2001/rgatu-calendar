# Design system РГАТУ

Источник визуального языка — архив публичного сайта `rsatu.ru`, а не произвольная стилизация.

## Что сохраняем из оригинала

- `Roboto` для основного текста.
- `Montserrat` для заголовков и служебных UI-акцентов.
- `#1f274b` — основной тёмный цвет.
- `#3f7480` — основной вторичный/интерактивный цвет.
- `#3333cc` — исходный primary token сайта; используем только там, где он действительно нужен.
- `#eef1f4` — базовый светлый фон.
- `#e2e7ee` — стандартная линия/граница.
- Белые поверхности.
- Радиусы преимущественно 9–16 px.
- Тени очень лёгкие: например `0 6px 18px rgba(31,39,75,.07)`.
- Базовая плитка оригинального сайта: padding 18×20, radius 11, border 1px, hover через бирюзовую границу и холодный фон.
- Красная вертикальная полоса у некоторых заголовков секций остаётся допустимым фирменным приёмом.

## Что не переносим буквально

Старую Bitrix/Bootstrap-разметку, исторические костыли, фиксированные ширины, устаревшую мобильную навигацию и декоративные компоненты, мешающие прикладным сценариям.

## Принципы продукта

1. Визуально это РГАТУ, а не абстрактный SaaS.
2. Один design system для студента, преподавателя и администрации.
3. Студенческие экраны — mobile-first.
4. Административные рабочие места — desktop-first и более плотные.
5. Карточки для навигации и сводки; таблицы для массового управления.
6. Красный — ошибка, конфликт, критический статус или фирменная структурная метка. Не основной CTA.
7. Цвет не является единственным носителем статуса.
8. Тени не заменяют структуру: основной разделитель — border.
9. Действия оформляются единообразно через `.rs-button`, статусы через `.rs-status`, рабочие панели через `.rs-panel`.
10. Все новые экраны используют токены из `frontend/src/design-system/tokens.css`.

## Структура

```
frontend/src/design-system/
  tokens.css
  foundation.css
  components.css
```

Экранные стили остаются в feature/page CSS и не должны вводить новые брендовые цвета без причины.
